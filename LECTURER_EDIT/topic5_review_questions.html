Topic 5 Review Questions

Use these questions for revision, tutorial discussion and self-study. Attempt each question before opening the suggested answer.

A. Machine Learning foundations

1. In simple terms, what is Machine Learning?
Suggested answer
Machine Learning is an AI approach in which a model learns patterns from data and uses them to make predictions, classifications or groupings.
2. What is the difference between supervised and unsupervised learning?
Suggested answer
Supervised learning uses examples with known targets or labels; unsupervised learning searches for structure without known target labels.
3. Distinguish regression from classification.
Suggested answer
Regression predicts a numerical value, while classification predicts a category or class.
4. Give one example of an unsupervised learning task.
Suggested answer
Grouping customers, students or farms into similar clusters without predefined labels.
5. Why does data preparation matter before Machine Learning?
Suggested answer
Models learn from the data provided. Missing, inconsistent, biased or poorly represented data can produce unreliable patterns and predictions.

B. Algorithms

6. How can linear regression be viewed as a Machine Learning algorithm?
Suggested answer
It learns a numerical relationship from labelled training examples and uses the fitted relationship to predict a numerical target for new examples.
7. What is the basic idea of a decision tree?
Suggested answer
A decision tree makes a prediction by following a sequence of questions or splits about the input variables.
8. State two advantages of decision trees.
Suggested answer
They are easy to visualise and explain, and they can model non-linear decision boundaries using simple rules.
9. What problem can occur if a decision tree becomes too deep?
Suggested answer
It may overfit by memorising details of the training data and generalising poorly to new data.
10. What does K represent in K-means clustering?
Suggested answer
K is the number of clusters that the algorithm is asked to create.
11. Why should K-means clusters be interpreted carefully?
Suggested answer
The algorithm will create K groups because it was instructed to, but the groups do not automatically correspond to meaningful real-world categories.

C. Evaluation and validation

12. Why should a model not be evaluated only on its training data?
Suggested answer
A model may memorise training examples. Evaluation on unseen data provides better evidence of generalisation.
13. What is a train/test split?
Suggested answer
It is a division of the available data into one subset used for training and another held back to evaluate performance on unseen examples.
14. Define overfitting.
Suggested answer
Overfitting occurs when a model matches the training data too closely but performs poorly on new data.
15. Define underfitting.
Suggested answer
Underfitting occurs when a model is too simple to capture important patterns even in the training data.
16. What does generalisation mean?
Suggested answer
Generalisation is the ability of a model to perform well on new examples that were not used during training.
17. What simple metric can be used for a classification problem?
Suggested answer
Accuracy, the proportion of predictions that are correct, is a simple introductory classification metric.
18. What simple metric can be used for a regression problem?
Suggested answer
Mean Absolute Error (MAE), which summarises the average absolute difference between predicted and true numerical values.
19. Why can accuracy be misleading for imbalanced classes?
Suggested answer
A model may achieve high accuracy by predicting the majority class most of the time while performing poorly on the minority class.
20. Summarise the full Machine Learning workflow introduced in this topic.
Suggested answer
Define the problem, prepare data, choose features and target when appropriate, split the data, train a model, evaluate it on unseen data, interpret the results and decide whether the model is useful.
