Topic 6 Review Questions

Use these questions for revision, tutorial discussion and self-study. Attempt each question before opening the suggested answer.

A. AI definition and scope

1. What is Artificial Intelligence?
Suggested answer
AI is the field concerned with designing computer systems that perform tasks associated with intelligent behaviour, such as reasoning, planning, learning, perception and language processing.
2. Why is AI broader than Machine Learning?
Suggested answer
Machine Learning is one AI approach, while AI also includes search, planning, logic, knowledge representation and rule-based reasoning.
3. What is an intelligent agent in simple terms?
Suggested answer
An agent is a system that receives information about its environment and selects actions towards a goal.
4. Give three examples of AI tasks that do not all use the same technique.
Suggested answer
Examples include route planning using search, expert-rule reasoning using logic, and image recognition using neural networks.

B. Search algorithms

5. What is a state in a search problem?
Suggested answer
A state represents a particular situation or configuration in the problem.
6. What is a state space?
Suggested answer
The state space is the collection of possible states that can be reached in the problem.
7. How does Breadth-First Search explore a problem?
Suggested answer
BFS explores level by level, visiting states that are the same number of steps from the start before moving deeper.
8. How does Depth-First Search differ from BFS?
Suggested answer
DFS follows one branch as deeply as possible before backtracking rather than exploring all states at the same depth first.
9. What is a heuristic?
Suggested answer
A heuristic is an estimate used to guide search towards states that appear closer or more promising relative to the goal.
10. Why can A* search be more efficient than uninformed search?
Suggested answer
It combines the path cost so far with a heuristic estimate of the remaining cost, so it can prioritise promising states.

C. Logic and reasoning

11. What is a fact in a rule-based AI system?
Suggested answer
A fact is a statement treated as known within the system.
12. What is a rule?
Suggested answer
A rule states that if certain conditions hold, then a conclusion can be drawn or an action may be recommended.
13. What is inference?
Suggested answer
Inference is the process of deriving a conclusion from known facts and rules.
14. State one advantage and one limitation of symbolic rule-based AI.
Suggested answer
Advantage: rules and reasoning can be inspected explicitly. Limitation: the system depends on the completeness and correctness of the encoded knowledge and may struggle with uncertainty or exceptions.

D. Neural networks

15. What are the three broad layer types in a simple neural network?
Suggested answer
Input layer, one or more hidden layers, and output layer.
16. What is the purpose of a weight in a neural network?
Suggested answer
A weight controls the influence of one connected value on another node.
17. What does an activation function do conceptually?
Suggested answer
It transforms a node's combined input and allows the network to represent relationships more complex than simple linear combinations.
18. What happens during neural-network training?
Suggested answer
The network makes predictions, compares them with target outputs and adjusts connection weights to reduce error over many examples.
19. Name two application areas where neural networks are commonly used.
Suggested answer
Examples include image recognition, speech recognition, language processing and other complex pattern-recognition tasks.
20. Why is the “most advanced” AI technique not automatically the best choice?
Suggested answer
The method should match the problem, available knowledge and data. A simpler search or rule-based method may be clearer, cheaper or more appropriate than a complex learning model.
